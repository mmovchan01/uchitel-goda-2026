# Портфолио Дмитрия Разгуляева

Статический сайт: сборка, зависимости и сервер не нужны. Оптимизированные фотографии находятся в папке `images`; её необходимо загрузить вместе с `index.html`.

## Размещение на GitHub Pages

1. Создайте на GitHub публичный репозиторий (например, `teacher-portfolio`).
2. Загрузите файлы из этого архива в **корень** репозитория: рядом с README должны находиться `index.html` и папка `images`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
5. После публикации адрес появится в разделе Pages. Обычно он выглядит так: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/teacher-portfolio/`. Публикация может занять несколько минут.

Если репозиторий называется `ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io`, сайт будет доступен по адресу `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/`.

## Фотографии

Фотографии памятника включены в файл страницы. Сведения об авторах, ссылки на оригиналы и лицензии Creative Commons указаны в подвале сайта. Портрет учителя пока не предоставлен — на странице оставлено место для фотографии.
