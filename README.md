# Портфолио Дмитрия Разгуляева

Статический сайт: сборка, зависимости и сервер не нужны. Оптимизированные фотографии находятся в папке `images`; её необходимо загрузить вместе с `index.html`.

## Размещение на GitHub Pages

1. Создайте на GitHub публичный репозиторий (например, `teacher-portfolio`).
2. Загрузите файлы из этого архива в **корень** репозитория: рядом с README должны находиться `index.html` и папка `images`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
5. После публикации адрес появится в разделе Pages. Обычно он выглядит так: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/teacher-portfolio/`. Публикация может занять несколько минут.

Если репозиторий называется `ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io`, сайт будет доступен по адресу `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/`.

## Фотографии

Фотографии памятника включены в файл страницы. Сведения об авторах, ссылки на оригиналы и лицензии Creative Commons указаны в подвале сайта. Портрет, диплом и фотографии мероприятий предоставлены пользователем.

## Добавление видео

В файле `index.html` найдите строку `const portfolioVideos = [];` и заполните список ссылками для **встраивания**, например:

```js
const portfolioVideos = [
  { title: 'Название видео', embedUrl: 'https://www.youtube.com/embed/ID_РОЛИКА' },
  { title: 'Второе видео', embedUrl: 'https://rutube.ru/play/embed/ID_РОЛИКА/' },
  { title: 'Третье видео', embedUrl: 'https://vk.com/video_ext.php?oid=...&id=...&hash=...' }
];
```

Используйте реальные ссылки встраивания из кнопки «Поделиться → Встроить» соответствующего сервиса. Примеры выше не являются работающими ссылками. Сайт поддерживает `youtube.com/embed/`, `youtube-nocookie.com/embed/`, `rutube.ru/play/embed/`, `vk.com/video_ext.php` и `vkvideo.ru/video_ext.php`. Ролики должны разрешать встраивание, а сервис должен быть доступен посетителю. Пока список пуст, сайт не загружает видеоплееры.
